# Será que é real? Guia contra deepfakes

Site estático em HTML, CSS e JavaScript puros, sem build. Explica como identificar vídeos e áudios falsos feitos por IA, os golpes mais comuns, o que fazer se for vítima e traz um quiz.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a branch `main`.
2. No repositório, abra **Settings › Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Salve. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Arquivos

- `index.html`: o site inteiro (estilos e script embutidos).
- `.nojekyll`: faz o GitHub Pages servir os arquivos como estão.
